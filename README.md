# Client Radar

MVP инструмента для клиентского менеджера корпоративного банка.

## Что умеет
- поиск компании по названию или ИНН;
- DaData через сервер, если задан DADATA_TOKEN;
- свежие публичные новости через бесплатные источники;
- дедупликация и классификация сигналов;
- банковская интерпретация и подбор продуктов;
- режимы Банк / Инвестор / Собственник;
- выбор событий и генерация черновика письма без платного AI;
- demo fallback.

## Запуск
npm install
npm run dev

## Переменные окружения
DADATA_TOKEN=

Без токена приложение продолжает работать.

## Vercel
Импортируйте репозиторий как Next.js проект и нажмите Deploy. DADATA_TOKEN можно добавить позже в Environment Variables.

Client Radar использует публичные данные. Выводы о потребностях компании являются аналитическими гипотезами и требуют проверки менеджером.
