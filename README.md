# M&A Bridge — демонстрационный каталог

Десктопный интерфейс для демонстрации бизнес-логики внутренней банковской платформы поиска встречных заявок на покупку и продажу активов.

## Состав демоверсии

- «Купить» и «Продать»: 8 активных вымышленных заявок (по 4 на каждую сторону).
- «Архив заявок»: 4 вымышленные закрытые заявки, включая реализованные (зелёный статус) и просто закрытые (серый статус). Возможна фильтрация по статусу.
- «Мои заявки»: 6 вымышленных заявок, условно созданных текущим демо-менеджером. В этом разделе карточки дополнительно показывают клиента и точный адрес.
- Меню «Разделы» с выдвижной панелью для навигации в «Мои заявки» и «Архив».
- Рабочие фильтры: текстовый поиск, тип актива, отрасль, география, стоимость (пересечение диапазонов), дата и сортировка; выбор направления покупки/продажи в «Моих» и «Архиве».
- Каждая заявка открывается по собственному URL \`/requests/ID\`. Есть кнопка возврата в нужный раздел.

## Важно: конфиденциальность

Абсолютно все клиенты, адреса, цифры и истории в каталоге — специально придуманные демонстрационные примеры, а не реальные данные банка.

**Это публичная демонстрация, а не защищённая система.** Условное ограничение показа клиента и адреса в интерфейсе не является контролем доступа: исходные демонстрационные данные доступны в коде, а URL \`?from=mine\` имитирует просмотр владельца. В реальном продукте потребуются корпоративная авторизация (SSO), серверные ACL, раздельное хранение публичной и закрытой части карточки, аудит доступа и раскрытия, согласования ИБ и банковских подразделений.

## Технологии

Next.js 15, React 19 и CSS. Нет БД, авторизации, интеграции с CRM, загрузки документов, сохранения/обновления реальных заявок или автоматического мэтчинга.

- \`npm install\`
- \`npm run dev\`
- \`npm run build\`
