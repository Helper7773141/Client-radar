# M&A Bridge — демо каталога запросов

Нейтральный интерфейс, ориентированный на рабочий стол. Две вкладки — «Купить» / «Продать». Список заявок, поиск, фильтры и отдельные страницы подробностей. В текущей версии доступны два **демонстрационных** объекта: запрос на покупку компании и предложение о продаже земельного участка.

### Данные

Вымышленные/примерные заявки взяты из предоставленных пользователем параметров. Не подключены база данных, авторизация, автоматический мэтчинг, создание новых заявок или сохранение изменений. Имена менеджеров воспроизводятся из предоставленных примеров. Сайт опубликован публично и не должен использоваться для реальных клиентских данных.

### Логика

- Покупка и продажа в разных вкладках.
- Фильтры по категории актива, географии, стоимости; текстовый поиск.
- Диапазон стоимости запроса считается совпадением, если пересекается с диапазоном фильтра.
- Отдельные URL для карточек: \`/requests/BUY-001\` и \`/requests/SELL-001\`.
- Для земли и компании разные наборы полей.
- Параметры промышленной площадки в земельной заявке — **необязательные и не заполнены**, они не приписываются объекту ИЖС.

### Команды

\`npm install\` · \`npm run dev\` · \`npm run build\`.
