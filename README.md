# M&A Bridge — интерактивная демоверсия

Нейтральный интерфейс для демонстрации внутренней платформы сопоставления спроса и предложения на корпоративные активы.

## Возможности

- Вкладки «Купить» и «Продать» с 8 активными вымышленными заявками.
- Отдельные разделы в левом меню: «Мои заявки», «Избранное», «Архив заявок».
- Звёздочка «Избранное» на каждой карточке, а также на подробной странице. В разделе «Избранное» работают те же фильтры, что в каталоге.
- В разделе «Мои заявки» кнопка «Добавить заявку» (также доступна в боковом меню). Модальное окно содержит выбор направления, категории актива, общие поля, поля по типу актива, список дополнительных параметров («Добавить параметр») и закрытые сведения о клиенте/адресе.
- Пользовательские заявки сразу появляются в общем каталоге соответствующего направления и в «Моих заявках». Карточка открывается на отдельном URL \`/requests/MY-...\`.
- Фильтры по категории, отрасли, региону, диапазону цены, дате, свободный поиск и сортировка.
- Архив разделён на «Реализована» (зелёный) и «Закрыта» (серый).

## Хранение

Демонстрационные заявки и избранное сохраняются **только в localStorage текущего браузера**. Нет базы данных, авторизации, синхронизации между компьютерами, серверных проверок владения, CRM и ролевого доступа. Удаление данных сайта/браузера удалит введённые заявки. Не вводите реальные сведения банка, контрагентов, адреса клиентов или коммерческую тайну.

**Конфиденциальность в демо только визуальная:** сведения о клиенте и точном адресе показываются при открытии своих карточек из раздела «Мои заявки», но это не защита информации. В рабочем банковском продукте нужно реализовать серверные проверки прав, разделение публичных и закрытых полей, журналирование, корпоративную аутентификацию и согласование ИБ.

## Разработка

- Next.js 15 / React 19, клиентское хранилище без backend.
- \`npm install\`, \`npm run dev\`, \`npm run build\`.
