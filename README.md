# M&A Bridge — визуальный MVP

Визуальная демоверсия внутренней платформы Экспобанка. Вкладки **Купить** / **Продать**, фильтры по активам, географии, сумме, типу сделки и дата размещения; единый отраслевой справочник.

**ВАЖНО:** здесь нет базы данных, авторизации, реальных клиентских заявок, сохранения, серверных транзакций, искусственно созданных сделок или аналитических событий.

## Отраслевой справочник

Используется ОКВЭД-2 (ОК 029-2014, КДЕС Ред.2). Клиентское приложение загружает готовый JSON по открытой ссылке https://raw.githubusercontent.com/prog815/okved2/main/okved2.json — 3 102 записи из публикации Росстата на 01.10.2026. Источник: https://rosstat.gov.ru/classification . Пакет данных не принадлежит СПАРК; использование его закрытой таксономии не заявляется. На сайте видны источник, дата и ошибки загрузки, если удалённый справочник недоступен.

Важно: ОКВЭД описывает **вид экономической деятельности**, а не тип продаваемого актива. Поэтому тип актива, география, тип сделки и сумма вынесены в отдельные фильтры.

## Разработка

- Next.js App Router, React, CSS, без серверных API и базы.
- npm install && npm run dev
- npm run build

## Публикация

GitHub репозиторий подключён к Vercel в исходной конфигурации. Коммит в main обычно инициирует деплой; проверяйте статус в панели Vercel. Приложение не предназначено для размещения реальных банковских данных.
