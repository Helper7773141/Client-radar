# New Project — мониторинг Банка России

Рабочий адрес: https://client-radar-zeta.vercel.app/

Информационная панель для сотрудников финансовых организаций: краткие сведения о публикациях ЦБ с датами, фильтрами, прозрачным происхождением фактов и переходом на оригинальные документы.

## Источники и ограничения охвата

- 5 потоков RSS: «Новое на сайте», пресс-релизы, выступления, официальные акты, проекты актов.
- 2 дополнительных каталога для сверки охвата: https://www.cbr.ru/analytics/na_vr/ и https://www.cbr.ru/project_na/.
- Это **не 100%-ное зеркало** всех URL ЦБ: сайт, документы, приложения, архивы, а также страницы с нестандартной структурой могут оказаться вне индексатора. При сбоях источников лента показывает состояние, а не уверяет пользователя в полноте.

## Анализ документов

- Главная карточка компактно показывает суть сразу, если материал уже обработан.
- «Все факты» раскрывает несколько важных предложений/строк первоисточника. В исходный документ можно перейти из каждой карточки.
- Фоновый сборщик обрабатывает HTML, таблицы, PDF и DOCX; PDF из сканов без текстового слоя могут быть недоступны для автоматического анализа.
- По нажатию на «Получить конспект» API пытается обработать HTML, таблицы, PDF и DOCX, если архив ещё не содержит выдержку.
- Без ключа OpenAI используется **автоматическое выделение предложений/значений**, а не смысловой ИИ-анализ; интерфейс явно это обозначает.
- ИИ в серверном on-demand обработчике можно включить, добавив в Vercel Settings → Environment Variables `OPENAI_API_KEY` (при желании `OPENAI_MODEL`), без передачи ключей в чате.
- Выводы, даты вступления в силу и юридический статус всегда нужно сверять с официальным документом. Дата обнаружения проекта в реестре не приравнивается к дате публикации.

## Фоновая проверка и хранение

- Workflow `.github/workflows/cbr-refresh.yml` пытается запускаться **каждые 5 минут** и после изменений кода сборщика в основной ветке.
- Workflow использует код `main`, читает предыдущий `data/feed.json` из ветки `cbr-feed-data`, обрабатывает новые публикации и сохраняет обновлённую версию **в ветку данных**, без повторной сборки сайта.
- Отдельная ветка — лишь промежуточное решение для MVP. Для промышленного мониторинга нужен PostgreSQL, задания с retry, журнал обходов, контроль целостности и метрики задержек.
- GitHub Actions не гарантирует точность запуска: задания могут задерживаться/пропускаться, особенно при высокой нагрузке. Важные публикации могут появиться позже пяти минут.
- `app/api/feed` предпочитает актуальный фоновый архив и обращается напрямую к официальным RSS в случае отсутствия или устаревания архива.
- Вкладка самостоятельно обновляет сведения раз в 15 секунд, но это **не** гарантирует получение новых данных ЦБ раз в 15 секунд.
- Чтобы убедиться, что работает **не только интерфейс**, проверьте репозиторий GitHub → Actions → «Bank of Russia — background refresh» → успешные запуски, изменения ветки `cbr-feed-data` и счётчик «Готовые конспекты» на сайте.

## Разработка

- Next.js App Router, React, Cheerio + Node-обработчики PDF и DOCX на запрос.
- Python, BeautifulSoup, PyMuPDF, python-docx — для фонового извлечения из публикаций и вложений.
- `python -m unittest discover -s tests -p 'test_*.py'` запускает офлайн-тесты (после `pip install -r requirements-monitor.txt`).
- `npm install`, `npm run dev` — локальный интерфейс.
- При ошибках Банк России / GitHub / Vercel нельзя генерировать фиктивные новости или статусы. Проблема должна быть заметна пользователю.

## Известные дальнейшие задачи

1. Единая PostgreSQL-база документов, версий, идентификаторов актов и дат принятия/регистрации/вступления в силу, со сравнением изменений.
2. Полное покрытие структурированных каталогов ЦБ, включая информационные письма, документы и архивы, плюс журнал сравнения с разделами источника.
3. Опциональное ИИ-конспектирование с указанием пунктов документа, статуса, круга затронутых организаций и строгой проверкой ключевых юридических выводов.
4. Работа со сканированными PDF с осмысленной проверкой качества распознавания.
5. Сервисные метрики полноты, SLA, ошибок и восстановление пропущенных интервалов.
6. Дополнительные источники (включая официальный Telegram) с проверенной атрибуцией и дедупликацией.

Проект независимый; не является официальным ресурсом Банка России.
