# M&A Bridge — простой визуальный MVP

Статическая демонстрация каталога заявок на покупку и продажу активов.

- Две вкладки: «Купить» / «Продать».
- В каждой вкладке одна **вымышленная демонстрационная заявка**.
- По нажатию на карточку открываются подробные параметры: отрасль, подотрасль, ОКВЭД, география, стоимость, тип сделки, выручка, бизнес-модель, заявитель и комментарий.
- Простой интерфейс с приоритетом на экран компьютера.
- **Нет** серверных заявок, сохранения, авторизации, клиентских данных и внешних API.

Запуск: \`npm install && npm run dev\`. Проверка сборки: \`npm run build\`.
