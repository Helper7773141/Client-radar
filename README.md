# New Project — мониторинг Банка России

Новая версия проекта Client-radar: информационная панель по публичным материалам Банка России.

## Что реализовано
- Автоматическое получение данных при посещении страницы, повторное обновление открытой вкладки каждые **15 секунд**.
- 5 официальных RSS-потоков: «Новое на сайте», «Пресс-релизы», «Новости и выступления», «Официальные нормативные акты», «Проекты нормативных актов».
- Оперативная лента, фильтры по источнику и тематике, поиск, сортировка, сохранение публикаций в браузере.
- Даты публикации (если RSS сообщает дату) и консервативное извлечение дат вступления в силу (только явные даты в анонсе).
- Каждая карточка ведёт на первоисточник. Статусы доступности каждого источника отображаются открыто.
- Никаких вымышленных новостей, искусственных дат или фиктивного «ИИ-анализа».

## Важные ограничения MVP
- Это **не полное индексирование всего сайта cbr.ru**, а мониторинг пяти RSS-потоков, которые сам Банк России публикует на официальном сайте.
- Доступность сайта ЦБ для запросов из Vercel не гарантирована. Если ЦБ блокирует запросы, карточки честно не показываются; отображается ошибка. Нужно проверить реальные серверные логи после деплоя.
- Интервал 15 секунд означает периодический запрос открытой страницы. На сервере поток кешируется на 15 секунд; реальная задержка зависит от публикации RSS, сетевого соединения, ответа ЦБ и хостинга. 1–10 секунд и отсутствие пропусков не гарантируются.
- Нет фонового сохранения архива, постоянной базы данных и обхода всего HTML/PDF. При исчезновении записи из RSS-ленты она может исчезнуть с главной страницы.
- Краткие аннотации берутся из `description` официального RSS, это **не ИИ-анализ полного документа**.
- Даты в карточках не являются юридическим заключением; нормативные акты следует проверять в первоисточнике.

## Архитектура
- Next.js App Router, React.
- `app/page.js`: панель и фильтры.
- `app/api/feed/route.js`: серверный JSON API.
- `lib/cbr.js`: запросы RSS, распознавание и удаление дублей, тематическая классификация, осторожный поиск дат.
- Для запуска: `npm install`, `npm run dev`.

## Следующий технический этап для профессионального мониторинга
1. Добавить постоянную БД (Postgres), таблицы событий, документов, версий документа, источников и запусков проверки.
2. Подключить серверный планировщик, очереди и журнал проверок с алертами при сбоях. По ограничениям Vercel Hobby встроенный Cron доступен лишь раз в день; в Pro — от 1 минуты, для 10-секундной проверки нужен внешний постоянно работающий сервис. Высокочастотный обход должен учитывать лимиты Банка России.
3. Индексировать разделы, не присутствующие в RSS (банковское регулирование, письма, официальные разъяснения, правовые акты, PDF и приложения). Сверять новые и изменённые документы по хешу и вести историю.
4. Обеспечить полноценный ИИ-анализ полного текста с цитированием фрагментов, подтверждёнными датами действия и ручной проверкой важных юридических выводов.
5. Отдельно интегрировать официальный Telegram с учётом технических и правовых ограничений доступа.
6. Настроить мониторинг задержки поступления документов и предупреждения о недоступных источниках.

## Обновление: октябрь 2026 — полный текст, карточки и фоновая проверка

- Карточка переворачивается: на лицевой стороне — новость, на обороте — короткий конспект по тексту страницы cbr.ru. Кнопка «Читать оригинал» остаётся на обеих сторонах.
- Endpoint `/api/summary?url=...` серверно открывает только `https://(www.)cbr.ru/` и извлекает основной текст HTML. PDF-файлы и некоторые динамические страницы пока могут быть недоступны для анализа.
- Без ключа `OPENAI_API_KEY` показывается **автоматическая выдержка из полного текста** (отбор информативных предложений), а не полноценный ИИ-анализ. Если добавить `OPENAI_API_KEY` в переменные Vercel и при желании `OPENAI_MODEL`, используется ИИ-конспект; при ошибке ИИ — выдержка.
- GitHub Actions workflow `.github/workflows/cbr-refresh.yml` запускает `scripts/sync_cbr.py` каждые пять минут по расписанию. Публикации и короткие выдержки записываются в `data/feed.json` в отдельной ветке `cbr-feed-data`.
- Ветка `cbr-feed-data` исключена из автосборок через `vercel.json`, чтобы не создавать 288 сборок в день. API сайта объединяет архив этой ветки с текущими RSS-лентами.
- GitHub Actions запуск по расписанию **не гарантирован ровно раз в 5 минут**: GitHub может задерживать или пропускать запуски. Для гарантированного SLA нужен отдельный планировщик/БД.
- RSS-потоки, включая дополнительные, не равнозначны индексации всех правовых актов, PDF, приложений и изменений сайта ЦБ. Не заявляйте 100% охват без сверки с каталогами документов и журналом аудита.
- После развёртывания проверить, что автоматический workflow действительно выполнился: GitHub → Actions → Bank of Russia — background refresh. Для старта можно запустить workflow вручную через Run workflow.
